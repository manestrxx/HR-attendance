# نظام الحضور والانصراف — HR Attendance System

نظام حضور وانصراف مخصص للجوال، يدعم العربية والإنجليزية.
مبني بـ Node.js وExpress وSQLite وTailwind CSS.

## الصفحات

| الرابط | الوصف |
|---|---|
| `/` | صفحة الموظف: تسجيل الحضور والانصراف بالرقم الوظيفي والرمز السري |
| `/hr` | لوحة الموارد البشرية: المتابعة اللحظية، السجلات، الموظفون، التصدير |

## المزايا

- **الرمز السري مشفّر** بـ bcrypt، مع قفل مؤقت لمدة 5 دقائق بعد 5 محاولات خاطئة.
- **الساعة متزامنة مع الخادم**، فلا يؤثر تغيير وقت الجوال على التسجيل.
- **منع الأخطاء الشائعة:** لا يمكن تسجيل حضور مرتين، ولا تسجيل انصراف قبل الحضور.
- **الورديات الليلية مدعومة:** الانصراف بعد منتصف الليل يُحسب ليوم الحضور.
- **لوحة لحظية:** تتحدث فورًا عند كل حركة، وتعرض من هم داخل العمل ومن انصرف ومن لم يحضر.
- **السجلات:** عرض بالحركات أو بالملخص اليومي، مع إضافة حركة يدوية أو حذفها.
- **إدارة الموظفين:** إضافة وتعديل وإيقاف وحذف، ورفع جماعي من ملف Excel أو CSV.
- **أوقات الدوام:** بداية ونهاية الدوام ومدة السماح وأيام العطلة، مع حساب التأخير والخروج المبكر والغياب تلقائيًا.
- **الأعذار:** يقدّمها الموظف من جواله (مع مرفق) أو يسجّلها الـ HR، ثم قبول أو رفض مع ملاحظة.
- **التذكيرات بالإيميل:** مواعيد متكررة (أسبوع، شهر، 3 أشهر، 6 أشهر، سنة، سنتين) تُرسل تلقائيًا عبر Resend.
- **التصدير:** ملف Excel بالإنجليزية بأربع أوراق (ملخص الموظفين، الملخص اليومي، الحركات، الأعذار)، أو CSV.
- **الوقت:** كل الأوقات بنظام 12 ساعة (AM/PM).
- **مواقع العمل (GPS):** أكثر من موقع بنصف قطر لكل موقع (افتراضيًا 150 م). الموظف يسجّل من أي موقع، أو من مواقع محددة له، أو يُستثنى.
- **حسابات HR متعددة:** مدير نظام، موظف موارد بشرية، ومشاهد فقط.
- **سجل التعديلات:** كل تعديل محفوظ باسم من قام به ووقته وما الذي تغيّر، مع تصدير Excel.
- **الإجازات الرسمية:** تقويم شهري، وأيام الإجازة لا تُحسب غيابًا ولا تأخيرًا.

## متغيرات البيئة (Render ← Environment)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `ADMIN_USER` | اسم مستخدم مدير الموارد البشرية | `admin` |
| `ADMIN_PASSWORD` | كلمة المرور الأولى للمدير | `admin1234` (يُطلب تغييرها عند أول دخول) |
| `APP_TIMEZONE` | المنطقة الزمنية للشركة | `Asia/Muscat` |
| `DB_PATH` | مكان ملف قاعدة البيانات | `./data/attendance.db` |
| `SESSION_SECRET` | مفتاح توقيع الجلسات | يُولَّد تلقائيًا |
| `RESEND_API_KEY` | مفتاح Resend للإيميلات (أو من صفحة الإعدادات) | — |
| `MAIL_FROM` | عنوان المرسل | `onboarding@resend.dev` |

## تفعيل الإيميلات

Render يمنع منافذ SMTP في الخطة المجانية، لذلك يستخدم النظام Resend عبر HTTPS:
1. أنشئ حسابًا مجانيًا في resend.com.
2. **API Keys ← Create API Key** وانسخ المفتاح.
3. في لوحة الـ HR: **الإعدادات ← الإيميل** والصق المفتاح، ثم أرسل إيميلًا تجريبيًا.
4. للإرسال لأي إيميل، أضف نطاق شركتك في Resend (Domains) واجعل المرسل مثل `HR <hr@yourcompany.com>`.

## الحفظ الدائم للبيانات (Turso)

خطة Render المجانية تمسح الملفات مع كل إعادة تشغيل، لذلك يحفظ النظام نسخة دائمة في **Turso** (قاعدة SQLite سحابية مجانية):
- كل عملية كتابة تُنسخ فورًا إلى Turso، وعند انقطاع الاتصال تُحفظ في طابور وتُعاد تلقائيًا.
- عند كل تشغيل تُسترجع كل البيانات من Turso قبل أن يبدأ النظام.
- حالة الحفظ تظهر في **الإعدادات ← حفظ البيانات**.

| المتغير | الوصف |
|---|---|
| `TURSO_DATABASE_URL` | رابط القاعدة من Turso (يبدأ بـ `libsql://`) |
| `TURSO_AUTH_TOKEN` | مفتاح القاعدة من Turso |

بدون هذين المتغيرين يعمل النظام محليًا فقط وتظهر رسالة تحذير للمدير.

## ملف رفع الموظفين

الأعمدة المطلوبة: `emp_no` و`name` و`pin`.
الأعمدة الاختيارية: `department` و`job_title`.
تُقبل أيضًا العناوين العربية: الرقم الوظيفي، الاسم، القسم، المسمى الوظيفي، الرمز السري.

- الرمز السري من 4 إلى 6 أرقام.
- إذا كان الرقم الوظيفي موجودًا مسبقًا تُحدَّث بياناته.
- يمكن تحميل قالب جاهز من لوحة التحكم.
